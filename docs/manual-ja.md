## 1. Prompt Studioとは

Prompt Studioは、画像生成AIアプリ「Draw Things」用のプロンプト管理ツールです。

- **単一のHTMLファイル**で動きます。インストール不要、ブラウザで開くだけです
- **完全オフライン**で動作します（AI補助機能とDraw Things API連携を使う場合のみ通信します。どちらもローカル通信です）
- データは**お使いのブラウザの中**に保存されます。外部サーバーには一切送信されません

### 何ができるのか

- タグ・LoRAを登録して分類する（Library）
- タグを組み合わせてプロンプトを作り、Draw Thingsへ直接生成指示を送る（Compose）
- 作ったプロンプトをグループ・フォルダで管理し、検索・置換・比較しながら育てる（Groups）
- AIが出力したプロンプト群を自動分割して一括登録する（Assist）
- **生成済み画像のフォルダを読み込んで、画像からプロンプトを逆引きする**（Preview）

最大の特徴は最後のPreviewです。Draw Thingsが生成した画像にはプロンプトや設定がメタデータとして埋め込まれており、Prompt Studioはそれを読み取って検索・再利用できます。「画像→プロンプト→また生成」という循環が作れます。

### 動作環境

- **推奨ブラウザ**: Google Chrome / Microsoft Edge（最新版）
- Safari / Firefoxでも基本機能は動きますが、一部機能（フォルダ選択・自動バックアップ関連）が制限される場合があります
- Mac / Windows どちらでも動作します（Draw Things連携はDraw Thingsが動くMacが前提です）

## 2. 導入方法（ダウンロードと起動）

1. GitHubリポジトリを開きます
2. `prompt_studio.html` をクリックします
3. 右上の「**Raw**」ボタンをクリックします
4. `Cmd + S`（Windowsは `Ctrl + S`）でファイルを保存します
   - ファイル名が `.html` で終わっているか確認してください。`.txt` などになっている場合は `.html` に変更して保存します
5. 保存したファイルをダブルクリックすると、ブラウザで開きます

これだけで使い始められます。2回目以降も同じファイルを開くだけです。ブックマークしておくと便利です。

## 3. バッチ生成スクリプト「Prompt Runner Unlimited」の導入と使い方

Prompt Studioの「Copy Batch」「Copy Script OPTIONS」で出力される1行1プロンプト形式は、このバッチ生成スクリプトに貼り付けて使うことを想定しています。**Prompt Studioとの組み合わせの基本形**なので、ぜひ導入してください。

apeboywired氏（https://apeboywired.com）が公開しているBatch Prompt Runnerをベースに、サイズ指定・LoRA個別OFF・インペイント対応などを追加した拡張版です。ZIPに `Prompt Runner Unlimited` として同梱しています。

### 3-1. できること

- 貼り付けたプロンプトリストを、**上から順に自動で生成してフォルダに保存**します
- プロンプトごとの解像度指定（`704x832 | prompt`）
- プロンプトごとのLoRA OFF（`--no-lora | prompt`）
- Inpaintモード: 現在のキャンバス画像＋マスクを全プロンプトに使い回してインペイント生成
- 生成完了後、Draw Things側の設定・プロンプトは実行前の状態に自動復元されます

### 3-2. 導入手順

1. ZIP内の `Prompt Runner Unlimited` ファイルをテキストエディタで開き、**中身をすべてコピー**します
2. Draw Thingsを開き、サイドバーの「**Scripts**」を選択します
3. 右上の「**+**」ボタンで新規スクリプトを作成します
4. コピーした内容を貼り付けて保存します（名前は好きに付けてOKです）
5. 以後、スクリプト一覧から選択して実行するだけです

### 3-3. 使い方

1. Prompt Studioで、GroupsタブのCopy Batch（またはComposeのCopy Prompt +）でプロンプトをコピーします（各タブの詳しい使い方は後の章で説明します。導入だけ先に済ませておけばOKです）
2. Draw Thingsでスクリプトを実行するとポップアップが開きます
3. 「Prompt list」欄に貼り付けて OK を押します
4. あとは上から順番に自動生成され、ピクチャフォルダに保存されていきます

生成完了後、「Batch complete: n image(s) generated」というメッセージが表示されます（エラー表示の見た目ですが、完了報告です）。

### 3-4. プロンプトの書式

1行に1プロンプトです。以下の形式に対応しています。

```
masterpiece, best quality, 1girl, ramen shop counter
704x832 | masterpiece, best quality, 1girl, portrait
1344x768 | masterpiece, best quality, landscape, wide shot
--no-lora | masterpiece, background only, no character
704x832 | --no-lora | masterpiece, simple background
# この行はコメントとして無視されます
```

- `幅x高さ |` を行頭に付けると、そのプロンプトだけ解像度を個別指定できます
- `--no-lora |` を付けると、そのプロンプトだけLoRAを外して生成します（`--lora-off` `--clear-lora` でも同じ）。サイズ指定と併用する場合はサイズが先です
- `#` で始まる行は無視されます

これらの書式はPrompt Studio側が自動で付けてくれるので、手で書く必要はほとんどありません。GroupsのプロンプトにサイズやLoRA OFFフラグを設定しておけば、Copy Batchでこの形式のまま出力されます。

### 3-5. ポップアップの項目

| 項目 | 説明 |
|---|---|
| Prompt list | プロンプトリストを貼り付けます |
| Negative prompt override | 入力すると、この実行中だけネガティブを上書きします（空欄なら現在の設定のまま） |
| Images per prompt | 1プロンプトあたりの生成枚数（1〜16） |
| Enable Inpaint mode | インペイントモード（下記） |

### 3-6. Inpaintモード

「Enable Inpaint mode」をONにすると、**現在キャンバスにある画像＋描いたマスク**を全プロンプトに使い回してインペイント生成します。

- 同じ構図で表情だけ変えたい、背景は固定してポーズだけ変えたい、といった用途に向いています
- 事前にキャンバスへ画像を読み込み、マスクを描いておく必要があります（無いとエラーで教えてくれます）
- **Inpaintモード中はプロンプトごとのサイズ指定は使えません**（サイズ指定行があるとエラーになります）

Previewタブでダウンロードした画像はメタデータ付きなので、キャンバスに読み込んでこのInpaintモードの素材にする、という連携が便利です。

### 3-7. 上級者向け: OPTIONS設定

スクリプト冒頭の `OPTIONS` を書き換えると、さらに細かい制御ができます。通常は変更不要です。

| 設定 | 初期値 | 説明 |
|---|---|---|
| seedStart / seedStep | -1 / 1 | -1ならランダムシード。0以上にすると固定シードから開始し、1枚ごとにseedStepずつ増加 |
| filenamePrefix | "batch" | 保存ファイル名の接頭辞 |
| negativePrompt | "" | ネガティブの既定値（ポップアップ入力が優先） |
| steps / guidanceScale / model / sampler / clipSkip / strength | null | 指定すると現在設定を上書き。PNGメタデータから設定を復元したいときに使えます |
| loras / mergeLoras | null / false | LoRA構成の上書き。`[]` で全LoRA解除、mergeLoras: trueで現在のLoRAに追加 |

### 3-8. 生成中の放置について（Mac）

バッチ生成中にMacがスリープすると処理が止まることがあります。ターミナルで

```
caffeinate
```

（モニターも消したい場合は `caffeinate -d` の代わりに `caffeinate -i`）を実行してからスクリプトを走らせると安全です。保存フォルダをiCloud上に設定しておくと、生成中の画像をiPhoneなど別端末からリアルタイムで確認できます。

## 4. データの保存について（最初に読んでください）

Prompt Studioのデータ（タグ、LoRA、Groups、設定）はすべて**ブラウザのlocalStorage**に保存されます。ファイル自体にデータが書き込まれるわけではありません。

これは次のことを意味します。

- 同じブラウザで開けば、前回のデータがそのまま残っています
- **別のブラウザで開くとデータは空です**（ChromeのデータはSafariからは見えません）
- **ブラウザの履歴・キャッシュを消去するとデータも消えます**

### データを守る3つの方法

| 方法 | 場所 | 説明 |
|---|---|---|
| **自動バックアップ** | Settingsタブ | データ変更のたびにブラウザ内へ自動保存（直近10世代）。何もしなくても有効です |
| **Export JSON** | Libraryタブ | 全データをJSONファイルとして書き出します。定期的な手動バックアップや、別ブラウザ・別PCへの引っ越しに使います |
| **Auto-import** | Settingsタブ | 起動時に指定したJSONファイルを自動読み込みします |

**最低限、大きな作業をした日はLibraryタブの「Export JSON」を押す習慣をおすすめします。**

## 5. 画面の全体構成

画面上部のタブで機能を切り替えます。

| タブ | 役割 | 例えるなら |
|---|---|---|
| **Library** | タグ・LoRAを登録して分類する | 食材庫 |
| **Compose** | プロンプトを組み立てて生成に送る | 調理台 |
| **Groups** | 完成プロンプトを保存・管理・改良する | 冷凍庫と整理棚 |
| **Assist** | AI出力の取り込み・翻訳・整形 | 下ごしらえコーナー |
| **Preview** | 生成済み画像の閲覧とプロンプト逆引き | 完成した料理から素材を取り出す場所 |
| **Settings** | テーマ・バックアップ・AI設定 | 保全庫 |

画面右端・左端の「↑」「↓」ボタンでページの最上部・最下部へ移動できます。

## 6. Library タブ — タグとLoRAの倉庫

左カラムがタグ管理、右カラムがLoRA管理です。

### 6-1. データのExport / Import

画面最上部にあります。

- **Export JSON**: 全データ（タグ・カテゴリ・LoRA・Stock・Groups・Folder）を1つのJSONファイルとして保存します
- **Import JSON**: JSONファイルを読み込みます。読み込む範囲をプルダウンで選べます
  - 「タグ+Groups」: すべて読み込み
  - 「タグ系だけ」: タグ・カテゴリ・LoRAのみ
  - 「Groupsだけ」: Groupsのみ

Importは**既存データに追加（マージ）**されます。同じ内容は重複登録されません。上書きで消えることはないので安心して使えます。

### 6-2. タグの登録

「プロンプトを貼り付けて登録」欄に、カンマ区切りのプロンプトをそのまま貼り付けます。

```
masterpiece, best quality, 1girl, solo, long hair
```

貼り付けると下にタグごとのプレビューが表示されます。

- **選択を登録**: プレビューでクリックして選んだタグだけ登録
- **全て登録**: 全部まとめて登録
- 既に登録済みのタグは自動でスキップされます

### 6-3. カテゴリ

タグは11のカテゴリに分類できます。

| カテゴリ | 内容の例 |
|---|---|
| quality | masterpiece, best quality など品質系 |
| character | 1girl, long hair, blue eyes など人物・キャラ描写 |
| clothes | dress, oversized clothes など服の種類・形状 |
| clothes/expression | wet clothes, torn clothes など服の状態変化 |
| emotion | happy, sad, embarrassed など感情 |
| pose/expression | sitting, looking at viewer など動作・視線 |
| style/technique | pixel art, watercolor など画風・技法 |
| background | outdoor, city, forest など背景 |
| camera/angle | close-up, from above など構図・カメラ |
| effect | bokeh, sparkle など画面効果 |
| other | その他 |

分類は手動でもできますが、**AssistタブのAIカテゴリ仕分け**を使うと自動で振り分けられます（後述）。

### 6-4. タグの一覧と検索

- 並び順: 「登録順」「A-Z」「あ-ん」で切り替え
- 検索欄でタグを絞り込み
- カテゴリバーでカテゴリ別に表示
- 「タグ先頭へ」「タグ末尾へ」ボタンで長いリストを一気に移動

### 6-5. 出力

タグをクリックして選択すると、下部の出力欄にまとまります。

- **Comma / Lines**: カンマ区切り・改行区切りを切り替え
- **Copy Output**: 出力をコピー
- **Select All / Clear Sel**: 全選択・選択解除

### 6-6. LoRAの登録（右カラム）

- 表示名・ファイル名（.ckpt）・ウェイト（0〜2、スライダー）・メモを入力して「**Add LoRA**」
- 登録したLoRAはComposeタブで選択して使います
- **LoRAセット**: よく使うLoRAの組み合わせに名前を付けて保存できます（例:「キャラ生成セット」）。ワンクリックでまとめて呼び出せます

## 7. Compose タブ — プロンプトを組み立てて生成する

3カラム構成です。左が現在の構成サマリー、中央がタグ・LoRA選択、右がプロンプト編集と出力です。

### 7-1. 基本の流れ

1. 中央の「使用するLoRA」でLibraryに登録したLoRAをクリックして有効化
2. 「カテゴリ別タグ選択」でタグをクリック → 右のポジティブプロンプト欄に追加されます
3. 右カラムでポジティブ／ネガティブプロンプトを整える
4. サイズ・Steps・CFGなどを設定する
5. 出力する（コピー or API直接送信）

### 7-2. ポジティブ／ネガティブプロンプト

- ポジティブ欄はタグクリックで追加されるほか、直接入力・貼り付けもできます
- **行頭トリガーワード**: キャラ名やLoRAのトリガーワードを入れておくと、コピー時に各行の先頭へ自動で付加されます。保存済みGroupの内容自体は変更されません

### 7-3. サイズ・生成設定

- **Batchサイズ**: プリセット（704×832、1024×1024、1344×768 16:9 など27種類）から選ぶか、幅・高さを直接入力
- **Steps / CFG Scale / Images per Prompt**: 空欄のままなら「current」= Draw Things側の現在設定をそのまま使います
- **Add to Group**: 今作ったプロンプトを、選択したGroupへ保存できます

### 7-4. 出力ボタン

| ボタン | 動作 |
|---|---|
| **Copy Script OPTIONS** | バッチ生成スクリプト用の設定込みコードをコピー |
| **Copy Prompt + ,** | プロンプト本文だけコピー |
| **Shuffle Prompts** | 並んでいるプロンプト行の順番をランダムに入れ替え |
| **Clear** | 入力欄をクリア |

コピーしたものは、同梱のバッチ生成スクリプト「Prompt Runner Unlimited」のポップアップに貼り付けて使います（導入方法は[3章](#3-バッチ生成スクリプトprompt-runner-unlimitedの導入と使い方)参照）。

### 7-5. Draw Things APIへの直接送信

Composeタブ下部の「Draw Things API」カードから、**コピペを介さずDraw Thingsに直接生成指示を送れます**。

| ボタン | 動作 |
|---|---|
| **接続テスト** | Draw Thingsとの接続を確認します。まずこれを押してください |
| **先頭1件生成** | プロンプトの1行目だけ生成します。お試しに便利です |
| **全行を順番に生成** | 全プロンプトを上から順に自動生成します |
| **停止** | 送信を中断します |

未指定のModel / Sampler / LoRA / 設定は、Draw Things側の現在設定がそのまま使われます。送信ログは下の欄に表示されます。

**→ 接続の設定方法は次章で詳しく説明します。**

## 8. Draw Things API連携の設定（初心者向け手順）

### 8-1. Draw Things側の設定（必須・1分で終わります）

1. Draw Thingsアプリを開きます
2. 設定（歯車アイコン ⚙️）を開きます
3. 「**API Server**」（HTTP Server）を**ON**にします
4. ポート番号はデフォルトの「**7860**」のままにします

これだけです。Draw Thingsの中に、外部から生成指示を受け取れる窓口（APIサーバー）が立ち上がります。

### 8-2. Prompt Studio側の設定

ComposeタブのDraw Things APIカードにあるURL欄が

```
http://127.0.0.1:7860
```

になっていることを確認します（初期値のままでOKです）。「保存」を押すと次回以降も記憶されます。

`127.0.0.1` は「このMac自身」という意味のアドレスです。Draw ThingsとPrompt Studioを**同じMacで**使う場合はこのままで動きます。

### 8-3. 接続テスト

「**接続テスト**」ボタンを押してください。

- ✅ 成功: Draw Things側の現在のモデル名などが表示されます
- ❌ 失敗: 下記を確認してください
  1. Draw Thingsが起動しているか
  2. Draw Things設定のAPI ServerがONになっているか
  3. ポート番号が7860か（変更した場合はURL欄も合わせる）

### 8-4. うまくいかない場合: CORSエラーについて

HTMLファイルを直接開いている（アドレスバーが `file://` で始まる）場合、ブラウザのセキュリティ制限（CORS）で接続がブロックされることがあります。

その場合の対処は2つあります。

**対処1: Draw Things側のCORS設定を確認する**
Draw ThingsのAPI Server設定に応答ヘッダー関連のオプションがある場合は有効にします。

**対処2: 付属のローカルサーバー経由で使う**
リポジトリに同梱のローカルサーバーを使うと、`http://localhost:ポート番号` でPrompt Studioを開けるようになり、CORS問題を回避できます（サーバーが `/dtapi` という中継窓口を用意し、Prompt Studioが自動で使います）。ローカルサーバーを使うと、後述の**Mac側自動バックアップ（30世代）**も有効になります。

※ ローカルサーバーは必須ではありません。`file://` で開いて接続できているなら、そのままで問題ありません。

### 8-5. iPadなど別の端末から使う場合

Prompt StudioをiPadのブラウザで開き、Mac上のDraw Thingsに生成を投げることもできます。

1. MacとiPadを**同じWi-Fi**に接続します
2. MacのIPアドレスを調べます（システム設定 → ネットワーク で `192.168.x.x` のような番号を確認）
3. Prompt StudioのAPI URL欄を `http://192.168.x.x:7860` に書き換えて「保存」
4. 接続テストを押します

つながらない場合は、Macのファイアウォール設定でポート7860の受信が許可されているか確認してください。

## 9. Groups タブ — プロンプトを育てる場所

完成したプロンプトをテーマ別に束ね、検索・置換・比較しながら改良していく、Prompt Studioの中心的な作業場です。左カラムがGroup一覧、右カラムが選択中Groupの詳細です。

### 9-1. Groupの作成と管理

- グループ名を入力して「**作成**」
- **Group検索**欄で一覧を絞り込み
- Group Detail側のボタン:
  - **Copy Batch**: Group内の全プロンプトをバッチスクリプト用の1行形式に変換してコピー
  - **Duplicate**: Groupを複製
  - **Rename** / **Delete**: 名前変更・削除

### 9-2. Folder（フォルダ）でGroupを整理する

Groupが増えてきたら、フォルダで階層整理できます。

- 「整理Folder名」を入力して「**Folder作成**」
- Groupを**ドラッグ&ドロップ**でフォルダに入れられます
- フォルダは折りたたみ・並べ替え・リネームができます
- フォルダを削除しても、**中のGroupは消えず「未整理」へ移動**します。誤操作で中身が消える心配はありません
- フォルダ見出しのチェックで、フォルダ内の全プロンプトを一括選択できます

### 9-3. プロンプトの追加

方法は複数あります。

| 方法 | 場所 | 用途 |
|---|---|---|
| Composeから「Add to Group」 | Composeタブ | 組み立てたプロンプトを保存 |
| 「貼り付けをGroupへ追加」 | Groups右カラム上部 | 複数行をまとめて貼り付け。`704x832 | prompt` 形式のサイズ指定付きもOK |
| 「プロンプトを最下部に直接追加」 | Groups右カラム最下部 | TITLE付きで1件追加。改行入りでも1行化して登録 |
| AssistのAI取り込み | Assistタブ | AI出力の一括登録（後述） |
| Previewから登録 | Previewタブ | 画像のプロンプトを直接登録（後述） |

### 9-4. 順番編集

- 「**順番編集開始**」→ プロンプトをドラッグで並べ替え → 「**確定して番号振り直し**」
- 「**Group全体を逆順**」で並びを一括反転

### 9-5. プロンプトの選択と一括操作

各プロンプトにはチェックがあり、**Groupをまたいで選択できます**。選択したものに対して:

- **選択をComposeへ / 追記**: Composeのプロンプト欄へ送信（上書き or 末尾追加）
- **Compare & Remixへ**: 複数プロンプトを並べて見比べながら、良いところを組み合わせた新プロンプトを作れます
- **選択から派生Group**: 選択したプロンプトだけの新Groupを作成
- **選択を結合Copy / 結合をComposeへ / 結合をGroupへ追加**: 複数プロンプトを**1つに連結**します。「クオリティタグ群」+「人物描写」+「画風」のような部品の組み立てに使えます
- **選択順に関連画像**: 選択したプロンプトに近い生成済み画像を検索して表示（Previewで画像フォルダを読み込んでおくと使えます）
- **Topスコア画像**: 選択プロンプトとの一致度が高い画像を上位から表示

### 9-6. 送信時のサイズ指定

- **送信サイズ**: Composeへ送るときの一時的なサイズ。Group保存内容は変わりません
- **ランダムサイズ**: サイズ候補を複数選んでおくと、選択プロンプトごとにランダムなサイズを付けてComposeへ送れます。同じプロンプトを色々なサイズで試したいときに便利です

### 9-7. 検索・置換（一括編集）

Groupsの目玉機能です。

- **検索**: 入力するとヒット箇所がハイライトされます。「前へ」「次へ」でジャンプ
- **検索語の保存**: よく使う検索語は「検索語を追加」で保存し、プルダウンから呼び出せます
- **置換**: 置換欄に入力して
  - 「**Active Groupに適用**」: 表示中のGroupに置換を実行
  - 「**全Group選択に適用**」: 全Groupの選択プロンプトに置換を実行（確認ダイアログあり）
  - 「**置換→差分保存**」: 元プロンプトを残したまま、置換後を新バージョンとして保存
  - 「**置換欄を末尾追加**」: 置換ではなく、選択プロンプトの末尾にテキストを追加
  - 置換欄を空にして実行すると「検索語の削除」になります
- **検索HitをComposeへ**: 検索にヒットしたプロンプトだけをまとめてComposeへ送れます（ランダムサイズ版もあります）
- **コメント検索**: TITLEやメモを対象に検索できます

### 9-8. 全Groupタグ抽出

左カラムの「全Groupタグ抽出」で、**全Groupを横断して特定のタグを含むプロンプトを探せます**。

- カンマ区切りはAND検索（例: `wet hair, swimsuit` → 両方含むもの）
- 「**抽出→選択**」: ヒットしたプロンプトを一括選択
- 「**選択→Group化**」: 選択したものから新Groupを作成

「全Groupに散らばっている水着シーンだけ集めて1つのGroupにする」のような整理が一瞬でできます。

### 9-9. 重複チェック

「**重複チェック**」を押すと、類似度の高いプロンプト同士をグループ化して表示します。

- 類似度のしきい値は調整できます
- 完全一致だけでなく「ほぼ同じ」も検出します
- その場で不要な方を削除できます

AIにプロンプトを量産させていると似たものが溜まりがちなので、定期的な掃除に便利です。

### 9-10. Library Palette

「Library Palette」を展開すると、**Groupsの画面内でLibraryのタグを検索して、編集中のプロンプトに直接挿入できます**。

- カテゴリ絞り込み・検索付き
- 「編集中へ挿入」「選択タグをコピー」「Groupへ新規追加」

プロンプトを推敲しながら「あのタグなんだっけ」をその場で解決できます。タブを行き来する必要がありません。

### 9-11. 各プロンプト行の機能

各プロンプトには個別に以下があります。

- 編集（元を残して差分保存も可能）
- 個別サイズ指定（`W x H`）
- **LoRA OFFフラグ**: そのプロンプトだけLoRAを外して送信できます（「LoRA OFF一括解除」で全解除）
- 複製・削除・Composeへ送信

### 9-12. AI文体Cleaner

「AI文体Cleaner」は、AIが書きがちな説明文調のプロンプト（"A realistic photo of a woman sitting..., while soft sunlight..."）を、画像生成向けのタグ形式に圧縮します。選択したプロンプトにまとめて適用できます。

## 10. Assist タブ — 取り込み・整形の補助ツール

### 10-1. AI生成プロンプト取り込み

GrokやChatGPTなどのAIに複数シーンのプロンプトを出してもらったら、出力を**そのまま**貼り付けます。

- `Prompt 1（タイトル）` / `Scene 1` / `1. タイトル` / `### タイトル` などの区切りを自動検出します
- AIへの指示時に「マークダウン形式で出力して」と頼むとフォーマットが安定します
- うまく分割されないときは、各プロンプトの間を**3行以上空ける**か、`---` だけの行を入れると確実に分割されます

手順:

1. 貼り付けて「**取り込みPreview**」→ 何件に分割されたか確認
2. 追加先Groupを選択（新規Group名を入れて作成もできます）
3. 「**Groupへ一括登録**」

タイトルはメモとして保存され、余計な説明文はある程度自動除去されます。

### 10-2. プロンプト群を1行ごとに分割

過去に溜めたプロンプト群（空行区切り・`---`区切り・サイズ付き行）を貼り付けて、1行1プロンプト形式に分割します。

### 10-3. AI Prompt Cleaner

説明文調のプロンプトを、タグ形式に圧縮します（Groupsの「AI文体Cleaner」の単体版です）。

### 10-4. 翻訳機能（Ollama使用）

※ この機能を使うには、Settingsタブでの[Ollamaの設定](#12-4-ai-backendollama)が必要です。使わなくてもPrompt Studioの他の機能はすべて動きます。

- **日本語 → English（単文）**: 日本語を入力してEnterかTranslateボタン。結果をクリックでコピーできます
- **バッチ翻訳 & 登録**: 1行1テキストで複数入力し、まとめて翻訳してLibraryに直接登録します

### 10-5. 改行プロンプトを一行化 & ストック

改行入りのプロンプトを1行に整えて「ストック」に保存します。ストックは検索でき、使いたいときに呼び出せます。

### 10-6. AIカテゴリ仕分け（Ollama使用）

Libraryに登録したタグを、AIが自動でカテゴリ分けします。

- **任意選択**: タグをクリックして選んでから実行
- **未分類一括**: uncategorizedのタグを全部まとめて実行
- **pose任意 / pose一括**: pose/expression系の細分化用
- 実行後はプレビューが表示され、**確認・手修正してから適用**できます。勝手に書き換わることはありません

## 11. Preview タブ — 画像からプロンプトを逆引きする

Prompt Studioの心臓部です。生成済み画像を読み込み、画像に埋め込まれたメタデータ（プロンプト・設定）を検索・再利用できます。

### 11-1. 画像フォルダの読み込み

1. 「**画像フォルダを選択**」を押します
2. Draw Thingsの保存先フォルダを選択します
3. 画像がサムネイル一覧で表示されます

- **読込モード**: 画像が大量にあるフォルダでは「高速:画像先行」を選ぶと、サムネイルだけ先に並べて、メタデータは画像選択時に読み込みます
- **並び順**: 更新日時・ファイル名・ファイルサイズ・画像サイズで昇順/降順を選べます
- **Thumbスライダー**: サムネイルの大きさを80〜220pxで調整できます

※ 画像はPrompt Studioにコピーされるわけではなく、その場で読み取るだけです。元のファイルはそのまま残ります。

### 11-2. メタデータ検索

検索欄にキーワードを入れると、**全画像のメタデータを横断検索**できます。検索対象はプロンプト全文、ネガティブ、Seed、Model、Sampler、LoRA名など、埋め込まれた生成情報すべてです。

例:

- `ramen` → ラーメンシーンの画像だけ表示
- LoRA名で検索 → そのLoRAを使った画像だけ表示
- `DPM++ 2M` → 特定サンプラーの画像だけ表示

「あの設定で生成した画像どこいったっけ」が即座に解決します。

### 11-3. 画像詳細パネル（右カラム）

サムネイルをクリックすると、右側に詳細が表示されます。

**表示される情報**: ファイル情報（名前・パス・サイズ・更新日時）、生成情報（DT Size / Seed / Model / Sampler / Steps / Scale / LoRAとウェイト）、Positive / Negative プロンプト全文、Rawメタデータ

**画像に対する操作**:

| ボタン | 動作 |
|---|---|
| 画像クリック / 拡大 | ライトボックスで拡大表示。「100%」で原寸表示に切り替え |
| **表示画像をDownload** | この画像をダウンロードします。**メタデータは保持されたまま**なので、Draw Thingsに読み込ませると「Draw Thingsで生成した画像」としてそのまま認識されます。コントロールに載せてインペイントやDepth検出の素材にする、といった使い方ができます |

**プロンプトに対する操作**:

| ボタン | 動作 |
|---|---|
| **Prompt Copy / Negative Copy / Seed Copy / Metadata Copy** | 各情報をコピー |
| **設定付き1行Copy** | プロンプトにサイズ等の設定を付けた1行形式でコピー |
| **設定メモCopy** | Seed・Model・Sampler等の設定情報をメモ形式でコピー |
| **Composeへ / 1行化してComposeへ / 設定付きComposeへ** | プロンプトをComposeに送って、すぐ次の生成に使えます |
| **Compare & Remixへ** | Groupsの比較パネルに送ります |
| **PromptをGroup登録 / 1行化してGroup登録** | 既存Groupまたは新規Groupに保存します |
| **LoRAをLibrary登録** | この画像で使われたLoRAをLibraryに登録します |

### 11-4. 抽出検索（プロンプトの一部分から検索）

Positive Prompt欄で**文字をドラッグ選択**して「選択部分を抽出」を押すと、その部分だけを使って:

- **抽出部分で画像検索**: 同じ表現を含む他の画像を探す
- **抽出部分でGroups検索**: 同じ表現を含む保存済みプロンプトを探す
- **抽出部分をLibrary登録**: その部分をタグとしてLibraryに登録

「この画像のこの表現、他でも使ってたっけ」を即調べられます。

### 11-5. 近似検索

- **画像Promptから近似Groups検索**: 表示中の画像のプロンプトに近い保存済みプロンプトを、スコア順に表示します
- **画像Promptから近似画像検索**: 似たプロンプトで生成された他の画像を探します
- 判定の厳しさは「ゆるめ / 標準 / 厳しめ」で調整できます

「この画像気に入ったけど、元にしたプロンプトどのGroupに入れてたっけ」が解決します。

### 11-6. 選択モード（複数画像の一括操作)

「**選択モード ON**」にすると、サムネイルをクリックで複数選択できます（Shiftで範囲選択、「表示中を選択」で検索結果全部）。

- **選択画像を1行化してCompose**: 選択した画像のプロンプトをまとめてComposeへ
- **選択画像をDownload**: まとめてダウンロード
- **選択画像を1行化して登録**: まとめてGroupへ登録
- 「サイズ付き」チェック: 送信時に各画像の生成サイズを付けます
- 「Positiveのみ」チェック: ONならNegativeを含めず送ります

## 12. Settings タブ — テーマ・バックアップ・AI設定

### 12-1. Theme

カラーテーマを切り替えられます。LIGHTチェックでライトモードにもできます。

### 12-2. Auto-import

起動時に自動でJSONファイルを読み込む設定です。「ファイル設定」でExport JSONで書き出したファイルを指定します。複数環境でデータを揃えたい場合などに使います。

### 12-3. Automatic Backup（自動バックアップ）

データが変更されるたびに、自動でバックアップが保存されます。**設定不要で最初から有効です**。

| 保存先 | 世代数 | 条件 |
|---|---|---|
| ブラウザ内（IndexedDB） | 直近10世代 | 常に有効 |
| Mac側JSONファイル | 直近30世代 | ローカルサーバー使用時のみ |

- 変更内容が前回と同じ場合はスキップされます（無駄な保存はされません）
- 「**今すぐBackup**」で手動バックアップもできます
- 履歴の「**復元**」ボタンでその時点の状態に戻せます。**復元前の状態も自動でバックアップされる**ので、間違えて戻しても取り返せます

※ ローカルサーバーを使っていない場合、Mac側の欄は「未接続」表示になりますが、これは異常ではありません。ブラウザ内バックアップだけで基本的には十分です。

### 12-4. AI Backend（Ollama）

Assistタブの翻訳・AIカテゴリ仕分けは、ローカルLLM「Ollama」を使います。**外部のAPIキーは不要です**。

セットアップ手順:

1. https://ollama.com からOllamaをインストールします
2. ターミナルでモデルを取得します: `ollama pull llama3.2`（他のモデルでも可）
3. SettingsタブのENDPOINTが `http://localhost:11434` になっていることを確認します
4. 「Fetch」を押すと、インストール済みモデルの一覧が表示されるので選択します

`file://` でPrompt Studioを開いていて接続できない場合は、ターミナルで以下のようにOllamaを起動してください:

```
OLLAMA_ORIGINS=* ollama serve
```

※ Ollamaを使わなくても、翻訳とAI仕分け以外のすべての機能は問題なく動作します。

## 13. よくある質問・トラブルシューティング

**Q. データはどこに保存されていますか？外部に送信されますか？**
A. すべてお使いのブラウザ内（localStorage / IndexedDB）に保存されます。外部サーバーへの送信は一切ありません。Draw Things API・Ollamaとの通信も、お使いのMacの中（またはLAN内）で完結します。

**Q. ブラウザを変えたらデータが消えました**
A. データはブラウザごとに保存されるためです。元のブラウザでLibraryタブの「Export JSON」を押してファイルを書き出し、新しいブラウザで「Import JSON」してください。

**Q. ブラウザのキャッシュを消したらデータが消えました**
A. localStorageも一緒に消えた状態です。Settingsタブの自動バックアップ（ブラウザ内10世代）は残っている可能性があるので、まず「履歴を更新」を押して復元を試してください。それも消えている場合は、Export JSONで書き出したファイルからImportしてください。

**Q. Draw Things APIの接続テストが失敗します**
A. 次の順で確認してください。(1) Draw Thingsが起動しているか (2) Draw Things設定のAPI ServerがONか (3) ポートが7860か (4) それでもダメならCORS制限の可能性があります → [8-4章](#8-4-うまくいかない場合-corsエラーについて)参照

**Q. 「全行を順番に生成」の途中で止めたい**
A. 「停止」ボタンで中断できます。送信済みの分はDraw Things側で生成が続く場合があります。

**Q. Previewで画像を読み込んでも、プロンプトが表示されません**
A. メタデータが埋め込まれているのはDraw Thingsが生成したPNGです。他アプリで加工・変換した画像や、スクリーンショットにはメタデータがありません。また「高速:画像先行」モードでは、画像を選択して「詳細読込」を押すまでメタデータを解析しません。

**Q. Previewの画像フォルダは毎回選び直しですか？**
A. ブラウザのセキュリティ上、フォルダの読み込みは開き直すたびに必要です（ファイル自体は一切変更されません）。

**Q. スマホ / iPadでも使えますか？**
A. ブラウザで開けば動作します。Draw Things API連携は、Mac側のIPアドレスを設定すれば別端末からも使えます（[8-5章](#8-5-ipadなど別の端末から使う場合)参照）。ただしPreviewのフォルダ選択はデスクトップブラウザが前提です。

**Q. ツール内のメッセージの口調が独特なのですが**
A. ずんだもん口調は開発時の名残りです。仕様です。
